# NeuralEngine Usage Policy

## Start

Run `neural status`.

## Search decision

Before editing determine whether prior project knowledge, decisions, experience or playbooks are relevant.

When relevant: run `neural search`, record exact query, IDs and provenance, and explain impact.

When not relevant: state that no search was required and explain why repository sources suffice.

## Brain writes

Every Brain write requires proposed-record preview, explicit user authorization and no automatic lifecycle promotion.

## Evidence

Review reports status, search decision, query and returned provenance when used, impact on work, or why search was unnecessary. Running only `neural status` is not substantive use.
